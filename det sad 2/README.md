## Сайт дидактических материалов МБОУ «Апельсин»

Простой статический сайт для размещения дидактических и методических материалов для педагогов и родителей.

### Структура

- `index.html` — главная страница с разделами:
  - главная секция с описанием;
  - блок «О сайте»;
  - каталог «Дидактические материалы» с переключением возрастных групп;
  - раздел «Родителям»;
  - футер с контактной информацией.
- `styles.css` — стили и оформление сайта.

### Как открыть сайт

1. Скопируйте папку проекта на компьютер.
2. Откройте файл `index.html` двойным щелчком или через браузер (Chrome, Edge, Firefox и т.п.).

### Технические детали

- Используется чистый HTML и CSS (без фреймворков).
- Для шрифтов подключён Google Fonts (`Nunito`).
- Переключение возрастных групп в каталоге материалов реализовано на CSS без JavaScript.

### Как добавлять материалы

- Найдите в файле `index.html` секцию с id `materials`.
- Внутри нужной возрастной группы (`data-group="small" | "middle" | "senior" | "prep"`) добавьте новый блок вида:

```html
<article class="material-card">
  <span class="badge">Направление</span>
  <h3>Название материала</h3>
  <p>Краткое описание, тема, цель.</p>
  <div class="meta">
    <span>Формат (PDF, презентация и т.п.)</span>
    <span>Возрастная группа</span>
  </div>
  <a href="ПУТЬ_К_ФАЙЛУ" class="link">Скачать материал</a>
</article>
```

При необходимости можно изменить цвета и отступы в `styles.css` (в самом верху файла заданы основные CSS‑переменные).
