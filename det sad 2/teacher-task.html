Материал с файлом

Как сделать задание понятным

  • Короткое название + 2–3 шага «что сделать».
  • Если нужен файл — приложите карточку/листок в PDF или картинку.
  • Выберите группу — после публикации задание увидят только ученики этой группы.

Быстрый чек‑лист

  1. Название заполнено
  2. Инструкция есть
  3. Файл прикреплён (если нужен)
  4. Группа выбрана

Черновик не виден ученикам. Опубликуйте его в списке ниже, когда будете готовы.
